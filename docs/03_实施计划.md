# 灵枢 NeuroAxis · 分阶段实施计划

> 依据《02_技术设计》与《01_产品需求与验收》的里程碑拆解为可排期的周级任务。

## 0. 计划总则

| 项 | 口径 |
|---|---|
| 节奏 | 按 P0（6 周）→ P1（8 周）→ P2（10 周）三阶段；P0 内部按周切片，每周五跑一次 1.3 指标全量 |
| 人力 | P0：1 Python（服务端+LangGraph）+ 1 控制/仿真（元件库+解释器）+ 0.5 AI 应用（Agent/评测/RAG）；P1 起加 1 前端（Vue 交互打磨） |
| 停走规则 | 任何一周 1.3 表指标退化 → 停下修复，不带病前进 |
| 铁律前置 | 确定性（trace 1000 次全等）是 P0 第 1 周的交付物，不是"以后再补"——它失效则覆盖率、回归、Debugger 全部无效 |

## 1. P0 垂直切片（6 周）：D1 全闭环

| 周 | 主题 | 交付物 | 依赖/风险 |
|---|---|---|---|
| W1 | 确定性内核 | ① ST 子集解释器骨架（类型/语句/TON 语义按 15.1 判定表）；② 虚拟时钟 + 扫描循环 + trace 落盘（15.2 Parquet schema）；③ 1000 次一致性测试进 CI ✅ | 第一优先级。解释器语义错 = 全线返工 |
| W2 | 工程模型上半 | ① Spec JSON Schema（V1~V16 中 schema 能表达的先做）；② Spec 加载/校验/版本链（8.2 DDL）；③ 表达式解析成 IR 语法树（Guard 非字符串）✅ | Schema 是 Spec 引擎第一块代码 |
| W3 | 工程模型下半 | ① IR→ST 生成器（PRG_Main 组合程序 + GVL/FB_Machine/PRG_Alarm 导出层；手自动/急停通配边/互锁兜底 R03 后置；SpecHash 头可追溯）✅ ② 静态检查器第一批规则：S01~S03、S11、S21 + R01/R02/R11（13.4 安全类不可关闭）✅；场景链路已升级为 Spec→生成 ST→仿真（06 文档 2b 节）✅ | R03/R04 需要 ST 控制流图；S02/S03/S11 行号待 W4 解析器位置信息；FB 调用与序列模板待 W4 |
| W4 | 仿真台 | ① 虚拟设备库 12 种核心设备（5.3 工期注记执行口径：注册机制 + 四族基类；其余 P1-W1 补齐）✅ ② 测试 DSL Runner（set/expect/assert_never/drive/inject/init 全语义，expect_seq 存在性检查先行）✅ ③ D1 样例工程（Spec + 桥接 + suite，内嵌 R/S 规则门 + 确定性）✅；场景案例记录 06 文档 2c 节 ✅ | 黄金基线与 G3/G4 闸门接入待 W5；expect_seq 严格次序检查待覆盖率门禁同期实现 |
| W5 | Agent 闭环 | ① Orchestrator 状态机（4.2）；② 工具契约 24 个（4.3）先行实现核心 8 个；③ Debugger 归因规则 D1~D8 + trace.summarize；④ LLM 网关（云 API/记账/预算熔断/多供应商 fallback） | 轮次预算与闸门语义硬编码 |
| W6 | 收口与验收 | ① 五道闸门 G1~G5 全通（14.1）；② 证据包（WeasyPrint）；③ Web 工作台核心页（工程列表/Spec 编辑/仿真报告/闸门审批）+ CLI；④ 评测集 20 题全流程跑通；⑤ P0 验收 14 条逐项打勾 | 评测集题目文本/IO 表需提前备好 |

**并行轨道**（不占关键路径）：评测集 20 题撰写（14.3 格式）；13 号平台契约摘录入 `docs/contracts/`；测试 DSL 文法定义。

## 2. P1 工程化（8 周）

| 周 | 主题 | 交付物 |
|---|---|---|
| P1-W1~2 | 导出与 HMI | PLCopen XML 序列化 + CODESYS 导入编译验证；虚拟 HMI 生成（18.1）；方言地址映射与三菱八进制单测（15.3） |
| P1-W3~4 | 服务端多人 | RBAC 双人复核接 13 号 9 章；审批哈希链；trace 对象存储；Web 多用户隔离 |
| P1-W5~6 | 真机影子 + 多任务 | Modbus TCP 读写验证；S7 影子模式（只读对拍 1h 一致率 ≥99%）；解释器双任务优先级（确定性保持） |
| P1-W7 | RAG 知识库 | 三层语料摄取管线 + pgvector/FTS 混合检索 + 强制引用（19.1~19.3）；recall@5 评测进 CI |
| P1-W8 | LangGraph 子图扩展 | Debug 归因子图 + 知识库问答子图 + 错误排障子图上线；等价回归集护航；P1 验收 8 项打勾 |
