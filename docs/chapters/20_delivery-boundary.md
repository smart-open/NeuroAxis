# 20. 对外交付边界（商业交付时必须补齐，勿重演 13 号的 C4~C7）


**结论：本产品的 11~19 章只覆盖了「软件做出来」；一旦独立对外收费，还必须过四道门——装得上（交付物可信）、有存量（割接）、有人伺候（SLA）、有报价（回款）。13 号在 v1.5 用 12.10~12.13 与 13.2.2 补齐了这四块，本产品独立交付时直接沿用其口径，不重写，只声明挂接点。**

| 缺口（13 号编号） | 本产品的挂接口径 | 交付前检查项 |
|---|---|---|
| C4 交付物可信（13 号 12.11） | `plcagent` PyPI 包、服务端部署包（含 Web 工作台）、SimHost 子进程 **全部签名/镜像摘要锁定 + RFC3161 时间戳**；部署包附 SBOM（SPDX/CycloneDX）。特别注意：matIEC 二进制随包分发前须书面确认 LGPL 义务已满足（源码可获取路径写入交付物），python-snap7 同口径子进程隔离 | 干净机（含甲方同款 EDR）部署即用，浏览器打开工作台；`plcagent --version` 验签通过 |
| C5 存量替换（13 号 12.12） | 本产品常与既有 PLC 程序共存：F10 反向解析前，先用影子模式只读对拍（10.2 阶段 1）替代「直接接管」；**谁拥有 PLC 写权限**是进场判型第一问，未交权前产品只做只读分析 | 首次进场登记表含「现有程序归属与写权限状态」 |
| C6 运维 SLA（13 号 12.13） | 评测集退化、LLM 供应商涨价/停服是运维期两大高频项；SLA 分级与远程支持边界沿用 13 号 P1~P4 分级；云通道故障的恢复目标写「切换备用供应商/降级到规则引擎」（16.3），不写「不可用」 | 质保条款含模型供应商变更预案 |
| C7 报价与回款（13 号 13.2.2） | 报价六项拆分：License（Web 工作台用户席位）/ 评测集定制（客户专用工艺题）/ 方言导出适配（按厂商单列）/ 知识库摄取（按手册页数）/ 年度维护 / 训练。**评测集与知识库是本产品独有的可计费项**，别免费送 | 合同含回款节点与「按 A/B/C 档交付」的验收口径 |

**一句话**：13 号 13.7.3 的结论对本产品同样成立——「文档写到了」不等于「能力有了」；本产品上线前先跑通 D1 全闭环（M0 等价物），再把 20 章这张表逐行勾掉。
