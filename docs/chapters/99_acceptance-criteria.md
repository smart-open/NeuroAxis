# 阶段验收标准

## 0. 验收总则

- 每阶段结束开验收会，逐条打勾；**任何一条不达标即不进入下一阶段**（与 11 章"数字退化就停下修"同口径）。
- 每条指标必须给出测量命令/脚本；没有可复现测量方法的指标视为未达成。
- 验收结果（含数据）追加进 `docs/acceptance/P{n}-signoff.md`，不覆盖旧记录。

## 4. 商业交付前检查（源自 20 章，逐行勾掉）

## 5. 持续指标（每周五，非阶段门禁）

1.3 量化指标表（D1 时长、通过率、确定性、成本、延迟）每周全量跑一次；**任何退化 >5 个百分点 → 冻结发版，先回退 Prompt/模板版本**（14.2 口径）。
